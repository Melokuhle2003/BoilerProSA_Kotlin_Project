# BoilerPro SA v5

## Major release
- Added native Android learner application source.
- Added Room offline lesson cache.
- Added WorkManager background synchronisation.
- Added encrypted session storage.
- Added daily local study reminder.
- Added native learner dashboard, learning, practice, mock-test and progress entry points.
- Preserved v4 server/admin platform.
- Corrected PVW 2-3 60° main-pipe training values to OD 323 mm, ID 309 mm, MD 316 mm, circumference ≈992.7 mm.
- Preserved exclusion of the 56° square-main/round-branch lesson.
- Preserved exclusion of welding and engineering drawing.

## Important
This is a source/deployment package, not a claim of a published APK or live production service. Configure the production HTTPS API URL and build/test the Android project in Android Studio before release.
